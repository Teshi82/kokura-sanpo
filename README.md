# こくら、よりみち。

福岡県北九州市・小倉中心部の観光、グルメ、まち歩きを紹介する非公式ガイドです。

公開URL: https://teshi82.github.io/kokura-sanpo/

## 構成

- `index.html`: 観光スポット、グルメ、散策コース、アクセス
- `style.css`: レスポンシブデザイン
- `script.js`: スマートフォン用メニュー、散策コース切替
- `credits.html` / `assets/photo-credits.json`: 写真の著作者・出典・ライセンス
- `assets/`: 写真とアイコン
- `.nojekyll`: GitHub Pagesで静的ファイルをそのまま配信

GitHub Pagesの配信元は `main` ブランチの `/(root)` です。ビルドや依存パッケージのインストールは不要です。

## 掲載情報

2026年10月24日時点の公式情報を基に作成しています。自治体・観光協会・各施設が運営する公式サイトではありません。旦過市場の写真は2017年撮影・再整備前の記録写真です。営業時間や通行状況などは各公式サイトで最新情報をご確認ください。散策コースと所要時間は本サイトによる提案です。

## 写真の利用条件

写真の権利は各著作者に帰属します。小倉城の写真はCC BY-SA 2.0、紫川と旦過市場の写真はCC BY-SA 4.0です。詳細な帰属表示と原典リンクは `credits.html` に掲載しています。

公開前にJavaScriptの構文、ローカルファイルとページ内リンクの参照を検査しています。実機・Safariでの動作や現地の経路、施設の営業状況は保証するものではありません。
